# EL — Elevate Labs Internship Tasks

Repository collection containing 6 sequential machine learning and software engineering internship projects (Tasks 1 through 6).

### Tasks Breakdown

* **`elevate-labs-task1/`**: Non-Functional Requirements (NFR) and software requirement text processing, dataset cleaning, and baseline distribution analysis (`Task_01.ipynb`).
* **`elevate-labs-task2/`**: Exploratory Data Analysis (EDA) on software requirement lengths, correlation matrix analysis, pairplots, and outlier visualization (`Task_02.ipynb`).
* **`elevate-labs-task3/`**: Feature extraction and text preprocessing pipelines for requirement classification.
* **`elevate-labs-task4/`**: Baseline ML classification modeling and performance benchmarking.
* **`elevate-labs-task5/`**: Hyperparameter tuning, optimization, and validation analysis.
* **`elevate-labs-task6/`**: K-Nearest Neighbors (KNN) classification, distance metric comparisons, decision boundary plots, cross-validation tuning (`k_vs_accuracy`), confusion matrix generation, and hardware deployment overview presentation (`Task_6.ipynb`).
